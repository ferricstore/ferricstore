An email request may be repeated

💥 Email example (SQS / RabbitMQ):

Worker #1 pauses during a Java GC cycle. In this example, the visibility timeout expires and Worker #2 picks up the job. Worker #1 may wake up and attempt the email request too.

🛡️ With FerricStore:

Lease fencing: Every lease receives an incrementing number. When Worker #1 attempts to finish with stale Token 101, FerricStore rejects the state write.

Illustrative: duplicate $250 Stripe request ✓ Stale state write rejected
