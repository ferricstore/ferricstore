from ferricstore import BudgetPolicy, WorkflowClient, complete, transition

client = WorkflowClient.from_url("ferric://127.0.0.1:6388")
flow = client.workflow(type="react-agent", initial_state="turn")

@flow.state(
    "turn",
    claim_values=["turn", "memory"],
    budget=BudgetPolicy(scope=lambda ctx: f"agent:{ctx.id}", amount=1, limit=10),
)
def turn(ctx):
    turn_no = int((ctx.value("turn", b"0") or b"0").decode())
    @ctx.effect(
        "agent-tool", "ai.tool",
        operation_digest=f"tool:{ctx.id}:{turn_no}:v1",
    )
    def call_tool():
        return agent.execute(ctx.payload)

    result = call_tool()
    if result.done:
        return complete(result=result.answer)
    return transition("turn", values={
        "turn": str(turn_no + 1).encode(),
        "memory": result.memory,
    })

$4,000 Runaway Infinite Loop

💥 The Hazard (Unbounded While-True):

An autonomous coding agent encounters a syntax error and loops 500 times trying hallucinated tool calls overnight, completely draining the OpenAI API credit budget.

🛡️ How FerricStore Prevents It (Budget Cap):

Durable Financial Spend Limit: Every turn records token cost in the durable context. If cumulative cost reaches $5.00 (or 15 turns), execution is immediately halted before burning money.

🚨 $4,000 Wasted API Bill ✓ Hardware-Enforced Budget Cap
⚡

Cascading 3rd-Party API Overload

💥 The Hazard (Blind Retry Storm):

When OpenAI or a 3rd-party web scraping API returns 503 / 429 Rate Limits, the unmanaged agent hammers the failing service with 100 req/s, causing permanent IP bans.

🛡️ How FerricStore Prevents It (Circuit Breaker):

Durable 3rd-Party Circuit Breaker: If 3 consecutive errors occur, the flow enters a persisted cooldown state before a later scheduled retry probes for recovery.

🚨 429 Rate Limit Ban & Outage ✓ Auto-Trip Circuit Breaker
🔄

Mid-Loop Worker Crash

💥 The Hazard (Stateless In-Memory Agents):

Worker machine reboots at Turn #8 (after spending $2.40). The script restarts from Turn 1, charging another $2.40 for duplicate reasoning steps.

🛡️ How FerricStore Prevents It:

Explicit Agent State: Completed turns and their outputs are carried in durable state. A replacement worker claims the next state after lease expiry.

💸 Double LLM Inference Spend ✓ Durable Turn State
🔨

Duplicate External Tool Side-Effects

💥 The Hazard (Unchecked Retries):

The agent creates a GitHub PR or charges a Stripe card, then crashes before saving completion status, creating 10 duplicate PRs on retry.

🛡️ How FerricStore Prevents It:

Guarded Tool Execution: Give every external tool call a stable operation digest, provider idempotency key, or ctx.effect(...) guard. Workflow state alone cannot deduplicate an external provider call.

🚨 10 Duplicate GitHub PRs / Charges ✓ Explicit Effect Protection
